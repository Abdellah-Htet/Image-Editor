# 🎨 Image Editor – Photo Filters

A simple and interactive **Image Editor** built using HTML, CSS, and JavaScript. This project allows users to upload images and apply different visual effects in real time using adjustable filters.

## ✨ Features

- 📁 Upload images from your device.
- 🎨 Adjust image saturation and contrast.
- ☀️ Control brightness.
- 🟤 Apply sepia effects.
- ⚫ Convert images to grayscale.
- 🌫️ Add blur effects.
- 🌈 Adjust hue rotation.
- 🔄 Apply invert effects.
- 👁️ Control image opacity.
- 🔃 Reset all filters to their default values.
- 💾 Download the edited image.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML Canvas API

## 🚀 How to Use

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Upload an image from your device.
4. Adjust the filters using the sliders.
5. Click **Download** to save your edited image.
6. Click **Reset** to restore the original settings.

## 🎯 Project Goal

The goal of this project is to practice JavaScript DOM manipulation, event handling, image processing, and working with the HTML Canvas API.
